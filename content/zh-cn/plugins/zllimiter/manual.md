## 关于

ZL Limiter 是一款限制器插件，具有以下主要特性：

- **纯净精度**：真实峰值限制与最高 32 倍过采样有助于控制采样间峰值并减少混叠。
- **瞬态控制**：通过可调节的前瞻、自适应恢复以及灵活的启动与释放设置来保护和塑造瞬态。
- **立体声完整性**：通过可自定义的声道差值控制来保持声场宽度。
- **直观工作流**：精心设计的界面包含实时滚动波形显示和全面的响度计量。

**`Oversample`（过采样）**

选择过采样倍率以减少混叠和采样间峰值，最高可达 `32x`。

- 推荐使用 `Off` 进行峰值保护
- 推荐使用 `4x` 进行精细调节以及导出/渲染
- 如果在 `4x` 下能听到瑕疵，推荐使用 `8x`、`16x`、`32x`

过采样会在奈奎斯特频率附近添加一个低通滤波器。因此，即使信号峰值低于上限，你也可能会观察到增益衰减。

更高的过采样倍率会增加 CPU 占用。如果播放时出现爆音或断音，请尝试降低倍率或在宿主中增大音频缓冲区。

## 中央面板

### 输入增益滑块

输入增益滑块是位于中央面板左侧边缘的垂直滑块。

调节进入限制器的信号电平。

下方的下拉框让你可以选择输入-输出增益链接模式：

- `Input`：调节 `Input Gain`（输入增益）而不进行相应的输出补偿
- `Linked`：当 `Input Gain`（输入增益）为正值时，在限制器之后应用等量的衰减

### 幅值分析仪

幅值分析仪占据了整个中央面板，显示三条曲线：

- pre 曲线：输入主链信号的幅值
- post 曲线：输出主链信号的幅值
- reduction 曲线：增益衰减的幅值

## 数值面板

数值面板显示响度与各项数值读数。

- 当宿主提供走带信息时，播放停止时测量暂停，播放恢复时测量重置
- 关闭或隐藏整个插件界面会中断测量；再次打开或显示界面时将重置电平表

| 操作                                                    | 效果                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------ |
| 双击 **True Peak**（真实峰值）行                        | 重置其保持的峰值                                                   |
| 双击 **Correlation**（相位相关度）                      | 重置其相关度统计数据                                               |
| 双击 **LUFS-M、LUFS-S、LRA 或 LUFS-I** 行               | 同时重置所有响度统计数据与响度直方图                               |
| 双击垂直**电平表**                                      | 重置其保持的最大衰减量与输出峰值                                   |

___

**`True Peak`（真实峰值）**

显示保持的最大真实峰值电平。

___

**`Correlation`（相位相关度）**

显示当前（左侧）与平均（右侧）立体声相位相关度。

___

**`LUFS-M`**

显示当前（左侧）与最大（右侧）瞬时响度（基于 400 毫秒时间窗口）。

___

**`LUFS-S`**

显示当前（左侧）与最大（右侧）短期响度（基于 3 秒时间窗口）。

___

**`LRA`**

显示响度范围。方括号表示临时测量值。

___

**`LUFS-I`**

显示当前测量周期内的积分响度。

## 界面控制

通常，你可以通过 `Shift` 开启精细调节，通过 `Ctrl/Command` 开启特殊调节。如果在按下 `Shift` 时鼠标滚轮方向被反转，你可以再次反转它（在界面设置面板中）以将其恢复正常。

**滑块**

- 在使用鼠标拖动或鼠标滚轮调节滑块时，可以通过 `Shift` 开启精细调节。
- 当滑块上有两个值时，可以使用鼠标左/右键来控制第一个/第二个值。

**下拉框**

- 可以使用鼠标滚轮来更改选择项。

**窗口大小**

- 可以拖动右下角的调整手柄来调整插件窗口大小。
- 推荐的窗口大小设置方法：
	1. 将 **Window Size Fix**（窗口大小固定）设置为 `OFF` 并点击保存按钮。
	2. 将插件窗口调整到你偏好的大小。
	3. 关闭插件窗口。
	4. 重新打开插件窗口。
	5. 将 **Window Size Fix**（窗口大小固定）设置为 `ON` 并点击保存按钮。
	6. 关闭插件窗口。
	7. 之后，插件每次打开时都将使用在步骤 2 中设置的窗口大小。

## 峰值限制

ZL Limiter 采用双包络架构，由主峰值包络、辅助支持包络、可变立体声链接以及可选的真实峰值限制组成。

#### 主级限制

主级负责衰减单个瞬态峰值。开启过采样时，该阶段还会抑制采样间峰值。

**`Lookahead`（前瞻）** 设置峰值到来前的分析时间。较高的数值会增加前瞻时间窗口，使增益衰减更早介入，从而实现更平滑的衰减；较低的数值会缩短前瞻时间窗口，将增益衰减推迟到峰值到达时，从而保留瞬态的冲击感。

**`Recovery`（恢复）** 设置单个独立峰值过后恢复至单位增益的最短时间。在大动态或持续限制期间，释放速率会自动放缓以最大程度减少失真。较高的数值会延长恢复时间，带来更干净、更透明的限制效果；较低的数值会缩短恢复时间，从而在瞬态之间最大化响度。

#### 支持包络

支持包络用于稳定宏观响度与密集峰值序列。通过在紧密相邻的瞬态之间维持衰减，它可以防止增益快速波动，并与主限制级分担动态衰减，从而使整体处理更纯净。

**`Attack`（启动）** 设置持续增益衰减介入所需的建立时间。较高的数值会延长启动时间，使初始瞬态仅由主限制级处理，仅在持续高响度期间才介入支持包络；较低的数值会缩短启动时间，在遇到高信号电平时立即应用持续增益衰减。

> 无论支持包络的 **`Attack`** 设置为何，单个峰值始终由主限制包络控制。

**`Release`（释放）** 设置信号电平降低后持续增益衰减恢复至单位增益的时间。较高的数值会延长释放时间，使信号逐渐平缓地恢复到单位增益；较低的数值会缩短释放时间，在大动态段落过后更快地恢复信号电平。

> 使用 **`Recovery`** 控制离散瞬态过后的增益恢复，使用 **`Release`** 控制密集、持续声音素材上的持续衰减。

#### 立体声链接

**`Stereo Delta`（差值）** 设置左声道和右声道之间允许的最大增益衰减差值。在 `0 dB` 时，声道完全链接以保持立体声平衡；较高的数值允许更高的声道独立性，能够提高感知响度，但可能会带来立体声声像偏移。

#### 真实峰值限制

开启后，输出级将抑制可能在数模转换或有损编码期间导致削波的采样间峰值。该阶段还会捕获在下采样至工程采样率时引入的重构峰值。

真实峰值限制在过采样设置为 `Off` 时依然保持生效，并且独立于界面的峰值测量模式。
