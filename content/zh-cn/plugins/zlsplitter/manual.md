## 关于

ZL Splitter 是一款多功能音频分离插件，具有以下主要特性：

- **多功能分离**：将音频信号分离为左/右声道、中/侧声道、低频/高频、瞬态/稳态或峰值/稳态分量，亦可运行于直通模式。
- **高精度分频**：低频/高频分离采用模拟匹配去曲解（de-cramped）IIR 滤波器或线性相位 FIR 滤波，提供 12、24 和 48 dB/oct 斜率。
- **动态与频谱分离**：基于 STFT 中值滤波模型的瞬态/稳态分离，以及基于动态包络跟随器的峰值/稳态分离。
- **直观工作流**：精心设计的界面包含支持 OCT 与 ERB 平滑的 FFT 频谱分析仪、实时滚动幅值分析仪以及波形显示。

信号路由通常如下所示：

```mermaid
flowchart LR
    A[输入] --> B(ZL Splitter)
    B --> C[输出 1] --> C1(处理 / 效果器) --> E[完整信号]
    B --> D[输出 2] --> D1(处理 / 效果器) --> E
```

## 控制面板

控制面板位于插件窗口左侧。它提供当前激活分离模式的特定参数，并在分离模式为 `None` 时自动隐藏。

### 左/右声道分离

___

**`Mix`（混合）**

调节左声道与右声道之间的交叉混合比例。在 `0%` 时，声道完全分离（左声道至输出 1，右声道至输出 2）。增加混合比例会使声道内容在两路输出间互相渗透。

___

### 中/侧声道分离

___

**`Mix`（混合）**

调节中声道与侧声道之间的交叉混合比例。在 `0%` 时，信号被纯净分离为中声道（和信号）与侧声道（差信号）。增加混合比例会引入中声道与侧声道之间的交叉串音。

___

### 低频/高频分离

___

**`Mix`（混合）**

交叉混合低频与高频信号。在 `0%` 时，低频与高频频段完全分离。

___

**滤波器类型（Filter Type）**

选择分频滤波器结构。

- `IIR`：无限冲激响应分频器，使用去曲解（de-cramped）Linkwitz-Riley 滤波器。具有零算法延迟、平坦的幅值响应以及模拟匹配的曲线特性。
- `FIR`：线性相位有限冲激响应分频器，使用时间反转 IIR 滤波。完全保持相位关系而不产生相位偏移，但会带来处理延迟。

> 当设置为 `IIR` 时，分频器会在截止频率附近引入全通相位偏移。请避免直接将分离输出与未对齐的原干声信号混合。如果确实需要级联 `IIR` 滤波器，请参考 [级联 IIR 滤波器](#级联-iir-滤波器)。如果需要零相位偏移，请使用 `FIR` 模式。

___

**滤波器斜率（Filter Slope）**

选择分频滤波器的斜率：

- `12 dB/oct`（2 阶 Linkwitz-Riley）
- `24 dB/oct`（4 阶 Linkwitz-Riley）
- `48 dB/oct`（8 阶 Linkwitz-Riley）

___

**`Freq`（截止频率）**

调节低频与高频频段之间的分频截止频率（`50 Hz` 至 `18 kHz`）。

___

### 瞬态/稳态分离

瞬态/稳态分离采用短时傅立叶变换（STFT）二维中值滤波模型，在频域中将瞬态事件与持续稳态音色分离开来。与峰值/稳态分离不共享参数。

___

**`Balance`（平衡）**

调节瞬态与稳态分量之间的平衡（`-50` 至 `+50`）。负值偏向稳态分量；正值偏向瞬态分量。

___

**`Strength`（强度）**

调节分离强度（`0%` 至 `100%`）。在 `0%` 时不进行分离；在 `100%` 时应用最大分离。

___

**`Hold`（保持）**

调节瞬态衰减时间（`0%` 至 `100%`）。数值越大，瞬态衰减越慢，保留在瞬态信号中的音符起音部分越长。

___

**`Smooth`（平滑）**

调节跨频段的频谱平滑度（`0%` 至 `100%`）。
- 为 `0%` 时，各频率 bin 相对独立地进行分离。
- 为 `100%` 时，信号被作为一个统一的频谱整体进行平滑分离。

___

### 峰值/稳态分离

峰值/稳态分离采用双时间窗口动态包络跟随器（类似压缩器的模型），将突发的瞬态峰值从持续的基础信号中分离出来。与瞬态/稳态分离不共享参数。

___

**`Balance`（平衡）**

调节峰值与稳态信号之间的灵敏度阈值（`-50` 至 `+50`）。数值越低保留的稳态信号越多；数值越高捕获峰值越激进。

___

**`Attack`（启动）**

调节峰值检测的启动响应时间（`0%` 至 `100%`）。数值越大启动越慢，使初始瞬态渗入稳态信号中；数值越小在瞬态到达时立即触发峰值检测。

___

**`Hold`（保持）**

调节峰值包络的释放恢复时间（`0%` 至 `100%`）。数值越大包络衰减越慢，峰值保持时间越长。

___

**`Smooth`（平滑）**

调节平均窗口大小（`1` 至 `100`）。数值越大越能平滑快速的动态波动，获得更稳定的宏观分离效果。

**窗口大小**

- 可以拖动右下角的调整手柄来调整插件窗口大小。
- 推荐的窗口大小设置方法：
	1. 将 **Window Size Fix**（窗口大小固定）设置为 `OFF` 并点击保存按钮。
	2. 将插件窗口调整到你偏好的大小。
	3. 关闭插件窗口。
	4. 重新打开插件窗口。
	5. 将 **Window Size Fix**（窗口大小固定）设置为 `ON` 并点击保存按钮。
	6. 关闭插件窗口。
	7. 之后，插件每次打开时都将使用在步骤 2 中设置的窗口大小。

## 级联 IIR 滤波器

当级联多个低频/高频 `IIR` 滤波器时（例如构建三频段分频器），必须对齐分支之间的相位偏移以保持互补求和：

```mermaid
flowchart LR
    A[输入] --> B1(截止频率 f1)
    B1 --> C[输出 1] --> B2(截止频率 f2) --> O1[输出 1 + 输出 2] --> F1[低频]
    B1 --> D[输出 2] --> B3(截止频率 f2) --> O2[输出 1] --> F2[中频]
    B3 --> O3[输出 2] --> F3[高频]
```
